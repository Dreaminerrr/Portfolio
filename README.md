# Personal Portfolio Website

A modern, dark-themed, glassmorphic portfolio website inspired by Piyush Mishra's portfolio design.

## Features
- **Modern Glassmorphism UI**: High-end frosted glass cards, subtle borders, and smooth hover glow effects.
- **Animated Background**: Multi-layer dynamic gradient mesh canvas with ambient floating glowing orbs.
- **Responsive Layout**: Fully responsive across mobile screens, tablets, and wide desktop displays.
- **Lucide Icon Integration**: Crisp vector iconography across skills, achievements, and contact elements.
- **Interactive Contact Form**: Direct form submission integration ready for FormSubmit.co.
- **Clean Semantic Structure**: Modular HTML5/CSS3/ES6 JavaScript.
